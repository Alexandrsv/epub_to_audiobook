# Интеграция Silero через локальный API

## Статус

Реализовано в ветках `feature/silero-provider` и
`feature/openai-compatible-api`. Проверены unit/API-тесты, реальные модели
`v5_ru` и `v5_5_ru`, запуск FastAPI, `ffprobe`, WebUI и сквозной сценарий
EPUB → Silero API → MP3 с ID3-тегами.

## Общая схема

- Все изменения выполнять в новых ветках:
  - `epub_to_audiobook`: `feature/silero-provider` от `main`;
  - `silero-tts`: `feature/openai-compatible-api` от `master`.
- Gradio оставить без изменений: текущая команда запуска и адрес `127.0.0.1:7860`.
- FastAPI запускать отдельно на `127.0.0.1:8000`.
- Модель, PyTorch и нормализация остаются в проекте `silero-tts`.
- В первую версию не включать Docker.

## Silero-сервис

- Добавить отдельную команду запуска FastAPI.
- Реализовать:
  - `GET /health`;
  - `POST /normalize`;
  - OpenAI-compatible `POST /v1/audio/speech`.
- Загружать модель один раз при старте API:
  - модель по умолчанию — `v5_5_ru`;
  - поддержать переопределение через `--model-path`;
  - поддержать устройства `auto`, `cpu` и `cuda`.
- Всегда применять `ru-normalizr` в TTS-режиме. При ошибке нормализации завершать запрос, не используя исходный текст.
- Обрабатывать текст в следующем порядке:
  1. разделить по маркеру абзаца `@BRK#`;
  2. нормализовать каждый абзац;
  3. разбить нормализованный текст на фрагменты до 140 символов;
  4. синтезировать фрагменты.
- Использовать встроенную постановку ударений Silero через `put_accent` и `put_yo`. Не подключать `silero-stress`.
- Добавлять паузы:
  - 120 мс между техническими фрагментами;
  - 750 мс между абзацами.
- Не применять автоматический silence trimming.
- Сериализовать инференс общим lock и запускать API с одним worker.
- Переиспользовать общую логику загрузки модели, нормализации и генерации между API и Gradio без изменения существующего интерфейса Gradio.
- Gradio и FastAPI должны запускаться независимо. При одновременном запуске модель будет загружена в каждый процесс отдельно.

## Изменения в epub_to_audiobook

- Добавить `--tts silero` и тонкий `SileroTTSProvider` поверх существующего OpenAI-compatible клиента.
- Минимально расширить `OpenAITTSProvider` точками настройки клиента, стоимости и лимита текста, не копируя его реализацию.
- Значения Silero по умолчанию:
  - URL — `http://127.0.0.1:8000/v1`;
  - модель — `v5_5_ru`;
  - голос — `eugene`;
  - язык — `ru`;
  - формат — `mp3`;
  - стоимость — `0`.
- Добавить CLI-параметр `--silero_base_url`.
- Передавать границы абзацев через маркер ` @BRK#`.
- Добавить вкладку Silero в WebUI с настройками URL сервиса, модели и голоса.
- `--output_text` должен сохранять исходный подготовленный EPUB-текст. Нормализованный вариант проверяется через `/normalize` или существующий Gradio.
- Не добавлять PyTorch, `ru-normalizr` и код модели в зависимости этого проекта.

## Лицензия в UI и документации

- Во вкладке Silero явно показать, что русские модели Silero v5/v5.5 распространяются на условиях CC BY-NC и предназначены для некоммерческого использования.
- Указать, что для коммерческого применения требуется подходящая лицензия Silero или другая модель/движок.
- Добавить кликабельные ссылки:
  - [лицензия Silero Models](https://github.com/snakers4/silero-models/blob/master/LICENSE);
  - [репозиторий Silero Models](https://github.com/snakers4/silero-models).
- Продублировать лицензионное предупреждение и ссылки в README рядом с инструкцией запуска Silero.
- В качестве возможной альтернативы для коммерческого сценария упомянуть MIT-модель `v5_cis_base`, отдельно пояснив отсутствие автоматической постановки ударений и обработки омографов.

## Проверки

- Golden-тесты нормализации:
  - числа;
  - даты и время;
  - валюты;
  - римские числа;
  - сокращения;
  - латиница;
  - ручные метки ударений.
- Проверить порядок «нормализация → разбиение» и лимит в 140 символов.
- Проверить, что `@BRK#` не произносится и создаёт абзац с заданной паузой.
- Добавить API-тесты `/health`, `/normalize`, успешной генерации MP3 и ошибок параметров.
- Добавить smoke-тест с реальным `.pt` и проверкой результата через `ffprobe`.
- Проверить CLI, WebUI, голос `eugene` по умолчанию и лицензионные ссылки.
- Добавить сквозной тест EPUB → Silero API → MP3 с ID3-тегами.
- Проверить параллельные запросы: модель загружается один раз, инференс безопасно сериализуется.

## Допущения

- Первая версия работает локально без Docker и API-аутентификации.
- FastAPI по умолчанию слушает только `127.0.0.1`.
- Gradio и FastAPI запускаются отдельными командами.
- Русские модели `v5_ru` и `v5_5_ru` используются только некоммерчески.
